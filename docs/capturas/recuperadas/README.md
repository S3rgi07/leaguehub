# Pantallas recuperadas

Capturas de la versión 1.1, obtenidas del grafo real de navegación con la cuenta demo en una
base Room de prueba. Las imágenes se exportan como artefactos de `RestoredViewsFlowTest`.
La base de prueba no se instala en el teléfono; al entrar con la cuenta demo el repositorio
crea su conjunto persistente de datos locales.
